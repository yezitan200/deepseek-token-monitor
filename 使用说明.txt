token-monitor V1.1.0 · 使用说明（先看这个）
========================================

它是什么
--------
一个跑在你自己电脑上的"用量统计小工具"。它在本机 8788 端口守着，把你的程序发往大模型 API 的请求
原样转发出去，同时把 token 用量、花费、账户余额记下来，并在桌面上显示一个置顶的小悬浮窗。

三步跑起来
----------
1. 把整个文件夹解压到一个**路径里没有中文和空格**的地方（例如 D:\token-monitor），双击
   token-monitor.exe。第一次运行 Windows 可能提示"Windows 已保护你的电脑 / 未知发布者"——
   点「更多信息」→「仍要运行」（这个程序没有买代码签名证书，属正常现象）。

2. 第一次会弹出「首次使用 · 填写 API Key」：填你自己的 API Key（**只用来查询账户余额**）。
   不想填也行——留空，等你的程序通过它调用过一次之后，它会自动沿用那次请求带的 Key。

3. 桌面上会出现小悬浮窗（余额 / 总用量 / 本轮花费）。不想要了：按 Esc 或点右上角 ✕ 关掉悬浮窗，
   双击 stop.cmd 停掉后台的统计代理。

把你自己的程序接进来
--------------------
只需要改一行：把程序里的 base_url 指向 http://127.0.0.1:8788

  Python：  client = OpenAI(api_key="你的key", base_url="http://127.0.0.1:8788/v1")
  Node：    new OpenAI({ apiKey: "...", baseURL: 'http://127.0.0.1:8788/v1' })

路径、请求头、请求体都是原样转发，API Key 照旧用你自己的，代理不保存、不外发。

需要什么
--------
- Windows 10 / 11（悬浮窗和启动器是 Windows 专用）
- Node.js（统计代理需要；如果你本来就在用 DSH，那已经装好了）
- 想用启动器里的"DSH 网页"那部分：只要 npm 全局装过 @deepseek-ai/dsh，启动器会自动检测到；
  没装也不影响统计功能，DSH 相关的按钮会自动隐藏

界面上的东西
------------
- 右上角齿轮 = 设置。左边是导航、右边是卡片，一共三页：
    · API Key     —— 填 / 改 / 清空余额查询用的 Key，右边开关可以明文显示
    · 性能监控    —— 悬浮窗正下方那个小窗的总开关，以及 CPU / 内存 / 电池功率三项显示内容
    · 余额提醒    —— 打开开关并填一个金额（元）：余额低于这个数时，悬浮窗上的余额数字会变红；
                     不想要就关掉开关（开关关着时填的数字会留着，下次开不用重填）
  保存后会按需要自动重启统计代理和悬浮窗，让设置立刻生效
- 悬浮窗正下方的小窗：显示 CPU 占用、内存占用、电池功率（台式机没有电池时显示 —）
- 悬浮窗右上角胶囊按钮：在「余额 / 用量」两页之间切换
- 把悬浮窗拖到屏幕边缘 12 像素以内松手 → 折叠成小标签；点一下标签就展开
- 悬浮窗上出现的 ≈ 前缀表示这些数字是估算值（上游没返回 usage 时按字符估的）
- 余额和花费都是**按当前价估算**，不等于账单金额

注意
----
- 别把 config.json 发给别人——里面是**明文**的 API Key（这个包里没有它，第一次运行会自动生成）。
- 这个程序只监听本机（127.0.0.1），局域网/外网都连不上它，这是刻意设计。
- 想改价格、换上游、关掉自动更新等：看 README.md 第五节「配置项」。
